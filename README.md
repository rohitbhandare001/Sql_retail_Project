# 🛍️ Retail Sales SQL Analysis

## 📌 Project Overview

This project focuses on analyzing retail sales transaction data using **SQL Server**.

The main objective is to explore sales performance, customer behavior, product categories, transaction patterns, and time-based sales trends using SQL queries.

This project demonstrates practical SQL skills that are commonly required for a **Data Analyst** role.

---

## 🎯 Project Objectives

The analysis aims to answer important business questions such as:

* Which product categories generate the highest sales?
* What are the high-value transactions?
* Who are the top customers based on total spending?
* How many unique customers are present in each category?
* Which month performs best based on average sales?
* How do sales transactions vary throughout the day?
* What customer and transaction patterns can be identified from the data?

## 📊 Dataset

The analysis is performed on a retail sales transaction dataset.

The main table used in this project is:

**`Retail_Sales`**

Important columns include:

| Column            | Description                   |
| ----------------- | ----------------------------- |
| `Transactions_ID` | Unique transaction identifier |
| `Customer_ID`     | Customer identifier           |
| `Sale_Date`       | Date of transaction           |
| `Sale_Time`       | Time of transaction           |
| `Gender`          | Customer gender               |
| `Age`             | Customer age                  |
| `Category`        | Product category              |
| `Quantity`        | Quantity purchased            |
| `Total_Sale`      | Total transaction value       |

## 🔍 Business Questions & Analysis

### 1. Sales on a Specific Date

Retrieve all sales transactions made on a particular date.

### 2. Category & Quantity Analysis

Identify Clothing transactions made during November 2022 where the purchased quantity was 3 or more.

### 3. Category-wise Sales

Calculate total sales generated by each product category.

### 4. Customer Age Analysis

Calculate the average customer age for customers purchasing products from the Beauty category.

### 5. High-Value Transactions

Identify transactions where the total sale amount is greater than or equal to 1,000.

### 6. Gender & Category Analysis

Analyze the number of transactions based on customer gender and product category.

### 7. Monthly Sales Performance

Identify the best-performing month in each year based on average transaction value.

### 8. Top 5 Customers

Identify the top 5 customers based on their total spending.

### 9. Unique Customers

Calculate the number of unique customers in each product category.

### 10. Time-of-Day Analysis

Analyze the number of orders during:

* 🌅 Morning
* ☀️ Afternoon
* 🌙 Evening

## ▶️ How to Run This Project

### Step 1 — Install SQL Server

Install:

* Microsoft SQL Server
* SQL Server Management Studio (SSMS)

### Step 2 — Create the Database

Open the SQL script in SSMS and execute the database creation/query setup.

### Step 3 — Load the Dataset

Create/load the `Retail_Sales` table with the required data.

Make sure the table contains the required columns:

```text
Transactions_ID
Customer_ID
Sale_Date
Sale_Time
Gender
Age
Category
Quantity
Total_Sale
```

### Step 4 — Run the SQL Queries

Open:

```text
sql/retail_sales_analysis.sql
```

Run the queries section by section in SQL Server Management Studio.
